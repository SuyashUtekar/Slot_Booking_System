4. REQUIRED DATABASE CONSISTENCY CHECK
---------------------------------------

Run this query after the load test against the PostgreSQL test database:

SELECT
    ts.id,
    ts.capacity,
    ts.booked_guests,
    COALESCE(SUM(
        CASE WHEN r.status = 'CONFIRMED'
        THEN r.guest_count ELSE 0 END
    ), 0) AS confirmed_guests
FROM time_slots ts
LEFT JOIN registrations r ON r.slot_id = ts.id
GROUP BY ts.id, ts.capacity, ts.booked_guests;

Acceptance conditions for every slot:

  booked_guests <= capacity
  booked_guests = confirmed_guests

If both conditions hold, the database capacity invariant and registration
counter reconciliation passed for this test run.
